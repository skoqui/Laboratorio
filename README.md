# Laboratório

Este repositório é meu **laboratório de estudos práticos em Cibersegurança**, onde organizo relatórios, testes e desafios resolvidos ao longo da minha jornada na área.

## 📂 Estrutura

- **Bugbounty/**  
  Estudos, anotações e testes focados em Bug Bounty, incluindo reconhecimento, exploração e análise de vulnerabilidades.

- **CTFs/**  
  Resoluções de desafios CTF (Capture The Flag), com foco em aprendizado prático e raciocínio técnico.

## Objetivo

- Consolidar conhecimento prático  
- Documentar aprendizados reais  
- Criar um histórico de evolução técnica  
- Apoiar estudos em Segurança da Informação

## Aviso

Todo o conteúdo aqui é **exclusivamente para fins educacionais**.  
Nenhuma informação deve ser utilizada de forma ilegal ou sem autorização.
